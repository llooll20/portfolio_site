# 프로젝트 구성

포트폴리오와 프로젝트를 포함한 요소를 사이트에 어떻게 구성할 것인지 정의한다.

## 사이트 메뉴

기본 주소: `http://mysite/`

- Home
- Portfolio
- Project
- Playground
- About

향후 게임, 위키 등의 요소를 확장할 수 있다.

## Home

사이트에 처음 들어왔을 때 보이는 페이지다. 사이트 정보와 다른 페이지로 이동할 수 있는 버튼이 필수로 필요하다.

### 포함되어야 할 요소

- 사이트 정보
- 다른 페이지로 이동

## Portfolio

포트폴리오 내용이 들어갈 페이지다. 포트폴리오 설명, 수행한 역할, 기간을 통해 프로젝트를 설명하고 프로젝트 파일과 사진을 제공한다.

### 포함되어야 할 요소

- 포트폴리오 정보
- 사진
- 프로젝트 파일 업로드
